Privacy Policy

personal-gmail-mcp · Last updated 4 September 2026

personal-gmail-mcp is a private, single-user tool. It exists so that its operator, Manas Pathak, can search his own Gmail from an AI assistant. It is not a product, it is not offered to the public, and it has no users other than its operator.

What it accesses

The application requests exactly one Google API scope, https://www.googleapis.com/auth/gmail.readonly, against the Google Account of the person who authorizes it. That scope is read-only. The application is technically incapable of sending, modifying, labeling, or deleting mail, and it requests no access to Google Drive, Calendar, Contacts, or any other Google service.

What it does with data

Message headers and bodies are fetched from the Gmail API on demand, in direct response to a request from the authorizing user, and returned to that same user's own assistant session. The application keeps no database and no persistent storage of any kind. Message content is not written to disk, not logged, and not retained after the request that fetched it completes. A short-lived Google access token is held in memory to avoid re-authenticating on every request, and it expires on its own within the hour.

What it never does

  • It does not transfer, sell, rent, or otherwise disclose Google user data to any third party.
  • It does not use Google user data for advertising, marketing, or any form of profiling.
  • It does not use Google user data to train, fine-tune, or improve any machine learning or AI model.
  • It does not permit humans to read Google user data, except the operator reading his own mail.

Limited Use

The use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access

Access can be withdrawn at any time from myaccount.google.com/permissions. Revocation invalidates the application's credentials immediately and permanently. Because nothing is stored, there is no retained copy of any message to delete afterwards.

Changes

If this policy changes, the revision date above will change with it. Given that the application has a single user, changes will not be announced by any other means.
